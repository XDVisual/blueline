# Blueline

A simple floor plan drawer for laying out a house: rooms, walls, doors, garage doors, windows, furniture, notes and measurements, all in feet, with a 3D view.

**Open it:** https://xdvisual.github.io/blueline/

Works with a mouse, a laptop trackpad, an iPad or an iPhone. On an iPhone or iPad, open the link in Safari and tap **Share → Add to Home Screen** to use it like an app.
